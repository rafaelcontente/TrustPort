# Trust Net Port

> "I am not building a new Internet. I am building the missing trust layer for the current one — and I prove it in a real pilot."

The **Trust Net Port** is the mandatory validation pipeline for AI-mediated decisions. Nothing generated by an AI Agent reaches the user without passing through structured, traceable validation.

## Architecture: The 5 Gates
1. **Schema & Data Contract**: Validates format, types, and mandatory fields (Pydantic).
2. **Domain Rules (Policy-as-Code)**: Enforces business and regulatory limits (e.g., DSTI <= 40%).
3. **Formal Verification (SMT)**: Proves constraints are satisfiable using Z3.
4. **Uncertainty (Conformal Prediction)**: Quantifies model confidence and calibration (ECE < 0.05).
5. **Fidelity & Explanation**: Generates SHAP-based counterfactuals and feature importance.

## Outcomes
- `APPROVED`: Passed all gates.
- `REPAIRED`: Failed schema/rules, returned to Agent for correction.
- `ESCALATED`: High uncertainty, requires human review.
- `REFUSED`: Hard rule violation, with counterfactual explanation.

## Engineering Rules
1. **Terminal Only**: Everything is built and executed via the terminal.
2. **Regression First**: Every bug fix or feature adds a test in `tests/regression/port/REG-<NNN>_<slug>.py`.
3. **100% English**: All code, comments, documentation, and commits are strictly in English.
